# ❌⭕ Tic-Tac-Toe AI

A modern, interactive **Tic-Tac-Toe game** where you can challenge an AI opponent across three difficulty levels.

Built with **HTML, CSS, and Vanilla JavaScript**, this project focuses on clean UI, responsive design, game logic, and an AI opponent powered by the **Minimax algorithm**.

## 🎮 Live Demo

**Play the game:**
https://hussainali-cs.github.io/Tic-Tac-Toe-vs-Bot/
---

## ✨ Features

* 🤖 Player vs AI gameplay
* 🎚️ Three difficulty levels:

  * Easy
  * Medium
  * Hard
* 🧠 Hard mode uses the **Minimax algorithm**
* ❌⭕ Choose your symbol
* 🏆 Player, Bot, and Draw score tracking
* ⭐ Best score saved in browser
* 🔊 Sound effects with on/off control
* 🌙 Dark/light theme
* ✨ Winning move animations
* 📱 Fully responsive design
* 🔄 New Game and Reset Score options
* ⚡ No backend required
* 🌐 GitHub Pages ready

---

## 🧠 AI Difficulty

### 🟢 Easy

The bot selects a random available position.

### 🟡 Medium

The bot uses basic game strategy:

* Attempts to win
* Blocks the player's winning move
* Prioritizes the center
* Chooses corners when possible

### 🔴 Hard

Hard mode uses the **Minimax algorithm** to evaluate possible game states and select the optimal move.

The goal is to make the AI extremely difficult to defeat.

## 🚀 Run Locally

No installation or dependencies are required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/tic-tac-toe-ai.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd tic-tac-toe-ai
```

### 3. Run the game

Open:

```text
index.html
```

in your browser.

You can also use **VS Code + Live Server** for a better development experience.

---

## 🌐 Deploy on GitHub Pages

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
6. Click **Save**.

Your game will then be available through your GitHub Pages URL.
